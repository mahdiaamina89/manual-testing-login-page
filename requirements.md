
# Login Page Requirements

## Project
Sample Login System

## Functional Requirements

REQ-001: The user must enter a valid email address.

REQ-002: The password must contain at least 8 characters.

REQ-003: The user must be able to log in with valid credentials.

REQ-004: The system must reject invalid credentials.

REQ-005: The system must show an error message when login fails.

REQ-006: The email field must not be empty.

REQ-007: The password field must not be empty.

REQ-008: Successful login must redirect the user to the dashboard.

## Assumptions
These requirements are created for learning purposes.

Actual application behaviour must be validated against its real specifications.
