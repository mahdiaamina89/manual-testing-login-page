
# Test Plan – Login Functionality

## 1. Objective
To verify that the sample login functionality works according to the defined requirements.

## 2. Scope of Testing
- Valid email and password
- Invalid email format
- Incorrect password
- Empty email field
- Empty password field
- Password minimum length
- Login error messages
- Successful login redirection

## 3. Testing Type
- Manual Testing
- Functional Testing
- Negative Testing
- Boundary Value Testing

## 4. Test Environment
Application: To be selected
Browser: Google Chrome
Operating System: macOS
Test Data: Dummy credentials

## 5. Entry Criteria
- Login page is accessible
- Requirements are available
- Test cases are prepared
- Test accounts are available

## 6. Exit Criteria
- All planned tests are executed
- Results are recorded
- Identified defects are documented
- Remaining risks are summarised

## 7. Deliverables
- Test scenarios
- Test cases
- Test execution results
- Bug reports
- Test summary

## 8. Status
Planning stage
