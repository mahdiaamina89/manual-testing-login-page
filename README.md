
# Manual Testing Project – Login Page

## Project Overview
This is a beginner-friendly manual software testing project focused on validating a login functionality.

The goal is to practice essential Quality Assurance (QA) activities and document the software testing process.

## Objectives
- Understand login requirements
- Design test scenarios
- Write manual test cases
- Execute tests on a demo application
- Compare expected and actual results
- Report defects with supporting evidence

## Testing Scope
- Valid login
- Invalid login
- Empty fields
- Email format validation
- Password length validation
- Error message verification

## Tools
- GitHub
- Google Sheets or Excel
- Google Chrome
- Markdown

## Project Files
- requirements.md
- test-plan.md
- test-scenarios.md
- test-cases.csv
- bug-reports/bug-report-template.md

## Project Status
Documentation in progress. Test execution has not yet been completed.
